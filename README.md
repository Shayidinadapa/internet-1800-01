A single sentence, at most 200 characters long, that pictures the modern message-road for a traveler from the year 1800, using only words and pictures from that traveler's own time: a post office, a library, a road, letters, a friend across the sea.

## Run it

```sh
node main.ts
```

The program writes the sentence to `entry.txt` in the output directory (`MAKEFUN_OUTPUT_DIR`, else `OUTPUT_DIR`, else `/output`), with no trailing newline. It checks the sentence first: 1 to 200 characters, one line, one sentence ending in a full stop, and free of every word coined after 1800 on its own list.
